# THE SUBSTATION 變電所

單一 HTML 的 3D 恐怖逃脫遊戲，76 KB，無任何外部素材。桌機與手機皆可遊玩。

用 [gamedev skill 系列](https://github.com/chris58530/gamedev-skills)（feel／3d／horror／mobile）製作。

## 玩法

程序生成的地下變電所迷宮。找齊 5 個保險絲開啟出口。
手電筒有電量限制，關燈會回充。**奔跑會發出聲音**——它靠聲音找你。
躲進置物櫃可以躲避，但躲太久呼吸會暴露位置。

前 150 秒沒有威脅，讓你先熟悉環境。之後它會醒來。

## 操作

| | 桌機 | 手機 |
|---|---|---|
| 移動 | W A S D | 左半螢幕拖曳 |
| 環顧 | 滑鼠 | 右半螢幕拖曳 |
| 奔跑 | Shift | 「跑」鍵 |
| 蹲下 | Ctrl | 「蹲」鍵 |
| 手電筒 | F | 「燈」鍵 |
| 互動／躲藏 | E | 「互動」鍵 |
| 暫停 | Esc | II |

## 技術

Three.js `0.180.0`（鎖版）。程序化建模與貼圖、21 種即時合成音效、
遞迴回溯迷宮生成、BFS 尋路的追逐者 AI、依裝置分級與動態解析度。
可在 `sandbox="allow-scripts"` 的不透明來源中運行。
